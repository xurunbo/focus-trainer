# 专注力与记忆力训练小程序

基于 Taro 4 + React + TypeScript 的跨端训练应用（H5 版本）。

## 功能

- 视频专注：观看视频保持专注，分心检测与结算
- 记忆力训练：物品记忆、数字矩阵、舒尔特方格、追踪训练
- 训练计划与角色系统：按计划推进训练，解锁角色与成就
- 数据统计：训练时长、得分趋势、排行榜

## 技术栈

Taro 4.1.9 / React 18 / TypeScript / SCSS Modules / zustand

## 本地开发

```bash
npm install --legacy-peer-deps
npm run dev:h5
```

## 构建与部署

```bash
npm run build:h5
```

推送到 main 分支即通过 GitHub Actions 自动部署到 GitHub Pages。
